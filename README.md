## Proyectos

### LoLINSIGHT
Plataforma web que consume las APIs de League of Legends (Data Dragon) para consultar campeones, objetos, estadísticas de jugadores y noticias del juego.
**Mi aporte:** integración y manejo de las APIs, diseño visual y estilos de la página, wireframe y ordenamiento de elementos.
**Tecnologías:** HTML · CSS · JavaScript · Riot Games API
